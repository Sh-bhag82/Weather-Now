Weather-Now 🌤️

A responsive weather application built using HTML, CSS, and JavaScript that provides users with real-time weather information through a simple and user-friendly interface.

🚀 Features

- 🌡️ Displays current temperature and weather conditions
- 🌍 Provides weather information for different locations
- 💧 Shows humidity and other weather details
- 🌅 Displays sunrise and sunset information
- 📱 Responsive and user-friendly interface
- ⚡ Clean and lightweight frontend design

🛠️ Technologies Used

- HTML5 – Structure of the application
- CSS3 – Styling and responsive design
- JavaScript – Application logic and API integration

🎯 Purpose

The project was developed to practice frontend web development, JavaScript, API integration, and responsive UI design.
